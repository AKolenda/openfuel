# Approved visual target (reference, not generated native components)

Text-only openfuel wordmark. Map takes priority. Default compact List with Cards optional. Price is
prominent, report age below, Maps control separately tappable to the right or across the row. Mobile
custom menus are bottom sheets; long content scrolls and actions remain reachable. No licence badge
in the docs header or decorative dots in guide navigation.

The current HTML/Android sample resembles this target more closely than the earlier iOS starter.
No native parity is claimed. Capture actual simulator/device output at small/regular sizes, large
text and relevant languages before approving a native visual port. Exact money and source conditions
remain more important than decorative consistency.

Website type uses system fallbacks and the imported styles; no proprietary font files are shipped.
The documented palette is a design reference only, not a claim that it automatically drives every
SwiftUI or Compose component. The authoritative executable styles remain in the relevant app sources.
