# OpenFuel — third-party brand references (study 09)

This is a visual design study, not legal clearance or a launch asset pack.
Brand names are real; ALL station records, prices, locations, amenities, offers,
report times and distances are fabricated. No affiliation or approval is implied.
Husky is a legacy-brand example, not a statement about any current outlet.

## Separate rights

Application code is MPL-2.0. Original map illustration and synthetic values are
CC0-1.0. Brand names, logos and other third-party material are NOT relicensed by
OpenFuel under either licence. No permission was obtained from the brand owners.
Public availability, a Wikimedia tag, a non-free reference rationale, or credit
is not an app-logo licence. Keep any written permissions and permitted use scope
with each asset before release. Legal review should address both copyright and
Canadian trademark law and any applicable contract terms.

## Image/network behaviour

The HTML uses actual externally hosted PNG references, not AI-generated logos.
The six images were viewed through web research, but their bytes could not be
retrieved into this build environment. Therefore they are NOT bundled/offline.
Images need a connection and may be blocked by an embedded preview. Initials
are displayed when loading fails. Rendering of the remote artwork in the local
browser was not verified; no fabricated branded screenshot is supplied.

Image hosts: thumb.wikimedia.org, upload.wikimedia.org, cdn.freebiesupply.com.
The HTML sends no referrer. Hosts still receive ordinary request metadata,
including a network address. No analytics, geolocation, or map SDK is added.
Production should use cleared, bundled or self-hosted static assets, not this
third-party hotlinking arrangement. The regular SVG map remains local.

The Go action opens a general brand search in Apple Maps or Google Maps, never
a route to a fictional address. Search results are not associated with demo prices.
